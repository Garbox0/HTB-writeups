# HTB Writeups en español

Repositorio personal de **Garbox0** con resoluciones técnicas de máquinas retiradas de Hack The Box.

El objetivo no es recopilar comandos aislados, sino documentar el razonamiento detrás de cada fase: reconocimiento, formulación de hipótesis, explotación, escalada de privilegios y lecciones aprendidas.

## Máquinas

| Máquina | Dificultad | Sistema | Técnicas principales | Writeup |
|---|---:|---|---|---|
| TwoMillion | Easy | Linux | API, control de acceso, command injection, OverlayFS | [Leer en español](./TwoMillion/) |

## Criterios de publicación

- Solo se publican máquinas retiradas.
- Las flags, cookies, tokens, credenciales e IPs temporales se redactan.
- Cada writeup explica el porqué de las decisiones, además de los comandos.
- Las pruebas se realizan exclusivamente en laboratorios autorizados.
